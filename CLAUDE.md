## Commands

```bash
cargo build --release      # also runs build.rs codegen
cargo test                 # 18 tests across geo, cigi, orion, simulator
cargo run                  # dev run (UDP :8008)
./target/release/cigi_trillium --gimbal-ip 192.168.1.42 --diag
```

To inspect generated Orion types:
```bash
cargo build && cat target/debug/build/cigi_trillium-*/out/orion_generated.rs | less
```

## Architecture

- `src/main.rs` — 50 Hz Tokio loop, UDP I/O, CLI args
- `src/simulator/mod.rs` — GimbalSimulator: all physics, modes, telemetry
- `src/geo.rs` — WGS84 geolocation (ECEF, NED, ray-cast, inverse geopoint)
- `src/config.rs` — Config struct; `config.toml` key=value parser (no deps)
- `src/faults.rs` — FaultState, OrionDiagnosticsPacket builder
- `src/bridge.rs` — GimbalBridge: TCP proxy to real Orion hardware
- `src/convert/to_orion.rs` — CIGI → Orion packet mapping
- `src/convert/to_cigi.rs` — Orion telemetry → CIGI response
- `src/orion/` — Re-exports types generated by `build.rs` from `OrionPublicProtocol.xml`
- `src/cigi/messages.rs` — CIGI v3.3 structs (hand-written per ICD)

## Key Patterns

**Preferred constructor:** `GimbalSimulator::with_config(cfg)` — not `Default`.

**Endianness:** CIGI packets are **little-endian**. Orion TCP wire protocol is **big-endian** (sync: 0xD0, 0x0D; Fletcher-16 checksum).

**Codegen:** `build.rs` parses `OrionPublicProtocol.xml` at compile time → `$OUT_DIR/orion_generated.rs`. Never hand-edit Orion types; modify the XML or build.rs instead.

**Config loading:** `config.toml` in the working directory is loaded at startup. Missing file → built-in defaults. Section headers are cosmetic; only `key = value` lines matter. Unknown keys are silently ignored.

## Gotchas

**Trapezoidal deceleration:** The decel branch condition is `stop_dist >= err.abs()` where `stop_dist = v²/(2a)`. Do NOT add an extra `max_accel * dt * dt * 0.5` term — it causes zero-velocity startup to skip to the decelerate branch.

**SensorControl field mapping** (non-obvious CIGI extension):
- `sensor_state` 4 → Geopoint mode (not in base CIGI v3.3 spec)
- `track_mode` bit 0 → Rate vs Position when `sensor_state=1`
- `ac_coupling` → zoom level (Position/Rate) or geopoint lat (Geopoint)
- `noise` → geopoint lon fraction (Geopoint mode only)

**Camera switch blackout:** `entity_lat/lon/alt` returns 0,0,0 for 200 ms (10 frames at 20 Hz) after a camera switch. Tests must account for this.

**Continuous pan:** `pan_limit_deg = 360` enables unlimited rotation. Shortest-path algorithm is used; reported angle wraps to (−180°, 180°].
